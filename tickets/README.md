# Tickets

One markdown file per ticket, named `T-001-short-title.md`. Ideas live in [BACKLOG.md](../BACKLOG.md) until promoted.

## Template

```markdown
# T-001: Title

- **Customer:** name
- **Status:** idea | open | in-progress | resolved
- **Priority:** low | medium | high

## Description

What is the issue?

## Notes

Progress, findings, next steps.
```
